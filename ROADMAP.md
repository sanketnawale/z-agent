# Z-Agent Roadmap

Z-Agent is a browser-based MainframeOps assistant built around Zowe CLI, Python, Docker, Zowe, and pluggable AI providers.

## Current MVP

- Session-based IBM Z connection setup
- Django frontend and FastAPI backend
- Zowe CLI integration
- Jobs dashboard
- Spool viewer
- Evidence-based spool diagnosis
- AI explanation through an AI Gateway
- Dataset Explorer
- JCL submit support
- USS Browser
- AI provider and model switching
- Docker and Docker Compose deployment
- Local/server Ollama support

## Near-Term Goals

- Improve public documentation
- Add screenshots and demo video
- Add clean API examples
- Improve error handling
- Add audit log for user actions and Zowe commands
- Add safer approval flow for JCL submission
- Add more rule-based spool diagnosis patterns
- Add tests for core diagnosis logic

## Future Goals

- REST API usage for CI/CD pipelines
- Safer job lifecycle automation: submit, monitor, diagnose, explain
- Role-based access and admin controls
- Kubernetes / Helm deployment option
- OpenTelemetry-friendly observability
- Explore ZoweX and MCP-style tool integration
- SMF analytics if authorized access is available

## Community Direction

The immediate goal is to make Z-Agent a serious Open Mainframe Project Sandbox candidate.

The long-term goal is to grow the project with users, contributors, governance, documentation, and real-world mainframe operations use cases.
